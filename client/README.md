# Client App

The frontend for the poultry management system is built with React, TypeScript, and Vite.

## Scripts

- `npm run dev` - start the Vite development server
- `npm run build` - build the production bundle
- `npm run preview` - preview the production build
- `npm run lint` - run ESLint

## Development notes

- The client communicates with the backend API running from the server app.
- Update the API base URL in the client configuration as needed for your local environment.
